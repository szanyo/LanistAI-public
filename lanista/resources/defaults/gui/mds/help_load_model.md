## Load Model

Select a valid model project from the tree. The detail and lineage previews are
read-only and update with the highlighted model.

- **Confirm** loads the selected valid model into the runtime context.
- **Edit** opens the selected model's edit workflow without loading another
  unrelated entry.
- Invalid model folders are shown separately and cannot be confirmed.
- **Cancel** preserves the current loaded model.

`enter` confirms, `F3` edits, and `esc` cancels.
