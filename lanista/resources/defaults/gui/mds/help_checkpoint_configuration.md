## Checkpoint Configuration

Select the checkpoint used by Evaluation, Inference, or a supported training
continuation. **Confirm** applies the highlighted checkpoint.

**Edit** changes its note, **Rename** changes its storage-backed name through
the guarded workflow, and **Delete** requires secure confirmation. Cancel
preserves the parent selection. Inference always requires an explicit valid
checkpoint; LanistAI does not silently substitute another one.
