## Choose Edit Target

Choose the model, optional session, and optional checkpoint whose metadata will
be shown in Edit. Selecting a broader target clears incompatible narrower
choices.

The lineage previews are read-only orientation. **Edit Details** opens the
editor for the resolved target; Cancel changes nothing. Disabled selectors mean
the current model has no valid item at that level.
