## New Session

Create either a fresh training session or a fork from an eligible parent
session/checkpoint. The selected strategy controls lineage and starting-step
metadata; it does not modify the source session.

Provide the requested name and description, select a valid parent when
forking, then Confirm. Cancel performs no storage mutation.
