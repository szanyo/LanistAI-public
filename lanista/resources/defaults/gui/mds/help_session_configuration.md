## Session Configuration

Select the session used by Configure. The details shown beside the list are
read-only until **Edit** opens the session metadata editor.

**Confirm** applies the highlighted session. **Delete** starts the secure
deletion workflow and may also change the active session/checkpoint selection.
Cancel preserves the parent dialog's selection.
