## New Model

Create a model project from the packaged empty template or clone from an
eligible parent model. The parent tree is a selector, not an editor.

Provide a valid model name, version, and optional description. Confirm creates
the model only after validation; Cancel leaves storage unchanged. When cloning,
the next dialog reviews exactly which source files will be transferred.
